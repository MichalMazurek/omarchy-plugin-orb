Orb now installs with the normal Omarchy plugin command:

```bash
omarchy plugin add https://github.com/tcballard/omarchy-plugin-orb.git --enable
```

Settings are created automatically, existing layouts stay intact, and shortcuts follow enable, disable and removal. Press **Super+Alt+O** to open the wheel.

Tested on the XPS.

**Upgrading from the v0.1.0 local installer?** Remove and add Orb once through the plugin manager. Your saved settings are retained.
